# HorizonOS

HorizonOS — это открытый Android-лаунчер, созданный для превращения смартфона в игровую консоль.

Проект предоставляет полноэкранный интерфейс, навигацию с помощью геймпада, библиотеку игр, встроенный файловый менеджер, интеграцию с эмуляторами и дополнительные функции для использования Android-устройства в качестве игровой системы.

## Возможности

- Полноэкранный интерфейс в стиле игровой консоли
- Навигация с помощью геймпада
- Управление через сенсорный экран
- Библиотека игр
- Встроенный файловый менеджер
- Запуск Android-игр
- Интеграция с эмуляторами
- Автоматическое сканирование игр
- Получение обложек, скриншотов и информации об играх
- Ручное редактирование информации об играх
- Динамический фон на основе выбранной игры
- Профиль пользователя с аватаром и никнеймом
- Светлая и тёмная темы
- Система настроек HorizonOS
- Управление Wi-Fi и Bluetooth
- Управление контроллерами
- Информация о хранилище
- Настройки яркости и режима сна
- Экран блокировки HorizonOS
- Интеграция с root / Magisk
- Пользовательские звуки интерфейса
- Фоновое атмосферное аудио

## Поддерживаемые платформы

HorizonOS рассчитан на работу с играми различных платформ в зависимости от установленных эмуляторов.

В числе поддерживаемых направлений:

- Android
- PlayStation
- PlayStation 2
- PlayStation Portable
- GameCube
- другие платформы, поддерживаемые установленными эмуляторами

Поддержка конкретных платформ и эмуляторов продолжает развиваться.

## Библиотека игр

Игры добавляются через встроенный файловый менеджер HorizonOS.

Для каждой игры могут храниться:

- название;
- платформа;
- расположение файла;
- используемый эмулятор;
- обложка;
- скриншоты;
- дополнительная информация.

При сканировании HorizonOS может автоматически получать информацию об играх из внешних источников.

### Источники информации

Используемые источники:

1. ScreenScraper
2. Libretro
3. TheGamesDB
4. IGDB
5. SteamGridDB

Для каждого поля используется источник с наивысшим приоритетом, содержащий необходимую информацию.

Ручные изменения имеют приоритет над автоматически полученными данными.

## Управление

HorizonOS создаётся с расчётом на управление при помощи геймпада.

Основные действия:

| Кнопка | Действие |
|---|---|
| D-Pad / левый стик | Навигация |
| A | Выбор |
| B | Назад |
| HOME / Xbox | Возврат на главный экран |
| START | Контекстное действие |

Также интерфейс поддерживает управление через сенсорный экран.

## Настройки

HorizonOS содержит собственный интерфейс настроек.

Основные разделы:

- Режим полёта
- Яркость экрана
- Bluetooth
- Экран блокировки
- Wi-Fi
- Хранилище
- Темы
- Уведомления
- Режим сна
- Контроллеры
- Система
- Настройки лаунчера

Некоторые функции требуют root-доступа или Magisk. Без root часть системных возможностей может быть недоступна в зависимости от версии Android и конкретного устройства.

## Звук

HorizonOS поддерживает отдельные звуковые окружения для различных частей системы.

Можно использовать:

- звуки интерфейса;
- звуки навигации;
- звуки подтверждения и отмены;
- фоновое атмосферное аудио;
- отдельное аудио для первоначальной настройки.

Поддержка пользовательских звуковых наборов также является частью проекта.

## Первоначальная настройка

При первом запуске HorizonOS предлагает настроить основные параметры системы:

- язык;
- никнейм;
- аватар;
- тему;
- необходимые разрешения;
- библиотеки игр;
- звуки и вибрацию интерфейса.

После завершения настройки пользователь попадает на главный экран HorizonOS.

## Технологии

Проект использует:

- Kotlin
- Jetpack Compose
- Android SDK
- Gradle

## Root и системные функции

HorizonOS может использовать root-доступ для расширенной интеграции с Android.

Это позволяет реализовывать функции, которые недоступны обычному приложению, включая отдельные системные настройки и управление поведением устройства.

При этом лаунчер может запускаться и без root-доступа, однако часть возможностей в таком режиме будет ограничена.

## О проекте

HorizonOS является независимым проектом и не является официальным программным обеспечением Nintendo или другой игровой платформы.

Проект использует собственный код, интерфейс и визуальные элементы.

HorizonOS не распространяет игры, ROM-файлы, прошивки консолей, ключи шифрования или другие проприетарные материалы.

Пользователь самостоятельно отвечает за наличие и использование игровых файлов и другого контента.

## Разработка

Проект находится в открытой разработке.

Основная цель HorizonOS — создать полноценную консольную оболочку для Android, в которой устройство ощущается как игровая система, а не обычный смартфон.
